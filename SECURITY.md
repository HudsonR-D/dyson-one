# Security

Dyson One is a read-only research ledger.

- No secrets belong in this repository.
- Ingest talks only to public JPL SSD / CNEOS HTTP endpoints.
- Do not add tools that can pay, launch, email vendors, or command hardware.
- GitHub Actions `daily.yml` may write snapshot files; it must not store API keys.
- Report issues via GitHub. There is no bounty program.
