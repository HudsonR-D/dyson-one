# Contributing

Read `AGENT.md` and `CHARTER.md` first.

- Scoring changes need a test. The Bennu case in `evals/cases.md` is frozen.
- Field names come from `docs/ONTOLOGY.md` only.
- Do not add actuators, paid APIs, secrets, or LLM scoring.
- Keep ingest polite: budgets cap lookups; send the Dyson One User-Agent.
- One concern per PR. Prefer a better snapshot over a new process.
